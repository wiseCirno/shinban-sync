# 配置

把 `config.example.yml` 复制成 `config.yml`。令牌只放在这份文件里，不要提交到仓库。

环境变量 `BANGUMI_CONFIG_PATH` 如果指向一个已经存在的文件，会比命令行里的 `-c` 更优先。

## 先填这些

- `tmdb_token`：网页搜索和 Telegram 订阅都要用。在 TMDB 设置里拿 API Read Access Token
- `downloader.aria2.base_url`：一般是 `http://127.0.0.1:6800/jsonrpc`
- `downloader.aria2.token`：Aria2 配置里的 `rpc-secret`
- `storage.provider`：`local`、`sftp`、`openlist` 里选一个

只用网页时，Telegram 那两项可以空着。只用机器人时，`telegram_bot_token` 和 `telegram_user_id` 要填。用户 ID 可以问
`@userinfobot`。

## 文件放哪

下载目录是 Aria2 下完的地方，媒体库目录是整理后要放进去的地方。

- 本机：`storage.local.aria2_path` 和 `target_path`
- SFTP：填主机、端口、用户。密码和私钥二选一。目录写服务器上的路径
- OpenList：填网页地址、用户和密码。目录写网盘里的路径

网页上没被选中的那一组不用填。

## 文件名

默认会放成这样：

```text
番剧名 (2026)/Season 1/番剧名 S01E01.mkv
```

想改的话，用尖括号写模板：

- 文件夹：`<filename> (<first_air_date.year>)/Season <season>`
- 文件：`<filename> S<season:02d>E<episode:02d>.<ext>`

还能用 `<subtitle>`、`<season_air_date>`、`<episode>`、`<language>`。尖括号里面可以写 Python 的格式，比如 `<season:02d>`
就是补成两位。

## 一条订阅里有什么

网页和机器人会帮你写。手改的时候：

| 字段              | 要不要写       | 是什么                             |
|-------------------|----------------|------------------------------------|
| `search_keyword`  | 要             | 去 ACG.RIP 标题里对的字            |
| `filename`        | 要             | 媒体库里用的名字，一般是原名       |
| `subtitle`        | 要             | 字幕组，得是程序已经认识的名字     |
| `season_air_date` | 要             | 这一季哪天开播，用来算该下到第几集 |
| `first_air_date`  | 第一季可以不写 | 整部剧第一季的开播日               |
| `season`          | 可不写         | 默认第 1 季                        |
| `episode_count`   | 可不写         | 默认 12 集                         |
| `language`        | 可不写         | 默认简体 `chs`                     |

## 网页和定时

```yaml
web:
  host: 127.0.0.1
  port: 3325
  token: ""
schedule:
  enabled: false
  mode: daily
  hour: 4
  minute: 0
  interval_hours: 12
  weekday: 1
```

`web.token` 空着时，本机打开不用密码。要给别人访问时再设一个，请求里带 `X-Shinban-Token`。

定时不用写 cron。`mode` 用 `daily`、`interval` 或 `weekly`。`weekday` 里 0 是周日，1 是周一。勾上自动同步以后，到点才会跑，跑完就停。

## 访问 ACG.RIP 太频繁时

一般不用改。真要改再用环境变量：

| 变量                           | 默认   |
|--------------------------------|--------|
| `ACG_RIP_MIN_INTERVAL_SECONDS` | `2.0`  |
| `ACG_RIP_RETRY_AFTER_SECONDS`  | `30.0` |
| `ACG_RIP_MAX_ATTEMPTS`         | `3`    |
