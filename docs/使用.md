# 怎么用

Shinban Sync 分成几块，可以只开你需要的。

| 你想做的事       | 命令                                  | 会不会一直占着                            |
|------------------|---------------------------------------|-------------------------------------------|
| 现在就同步一轮   | `shinban-sync sync`                   | 下完这一轮就退出                          |
| 打开网页管理     | `shinban-sync web`                    | 网页开着。点同步时另外跑一轮，跑完就停    |
| 用 Telegram 订阅 | `shinban-sync bot`                    | 机器人一直听消息。`/refresh` 也是另跑一轮 |
| 到点自己同步     | `shinban-sync run --modules schedule` | 只有到点才跑，跑完退出                    |

网页、机器人和定时可以写在一起：

```bash
shinban-sync run --modules web,bot,schedule -c config.yml
```

`sync` 不要和它们写在同一个 `--modules` 里。它就是一次性的。

## 安装

首先确认 Python 版本在 3.13 或更高

```bash
cp config.example.yml config.yml
poetry install
poetry run shinban-sync web -c config.yml
```

装完以后也可以直接打 `shinban-sync`，不必每次加 `poetry run`。

打开网页只需要这一条。第一次会自动安装前端依赖并构建，之后直接启动。浏览器打开 <http://127.0.0.1:3325>。本机需要已安装 [pnpm](https://pnpm.io/)。

## 网页

- **订阅**：看已经订了什么，可以删，也可以手填一条
- **搜索**：先出番剧，再选季度，再选字幕组。等待的时候会转圈
- **配置**：填 Token、Aria2 和存放位置。没选中的存储方式会变灰
- **同步**：选每天、隔几小时或每周，也可以马上同步一次。日志可以展开，超过七天的会删掉

## Telegram

- `/subscribe 番剧名`：看海报，选季，选字幕组
- `/refresh`：马上同步一轮

机器人只认配置里的那个用户 ID。
